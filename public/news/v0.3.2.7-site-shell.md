# Demonym Connect v0.3.2.7

Web Connect is starting to feel a little more like a real place instead of only a battle test screen.

- Added the new site header and navigation.
- Added About, News, Ladder, Support, and Settings pages.
- Added Light / Dark and Simple / Sharp theme controls.
- The new Sharp theme is a restrained Metalheart / Depthcore-inspired pass while keeping the battle UI readable.
- The existing v0.3.2.6 battle, reconnect, cleanup, and sprite work stays intact.

The Ladder is only a placeholder for now, but it gives the future ranked side of Connect a home.
