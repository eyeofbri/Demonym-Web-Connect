# Demonym Connect news posts

Drop simple `.md` or `.txt` files in this folder and commit them normally.

The News page reads this folder from the public GitHub repository, asks GitHub for the latest commit touching each post file, and sorts the posts newest-first by that commit date. Files whose names start with `_` are ignored, so this README does not appear as a post.

Minimal Markdown supported by the site: headings, paragraphs, bullet lists, bold, italic, inline code, and normal `https://` links.
